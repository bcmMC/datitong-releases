# 答题通

Android 10 及以上的悬浮解题助手，支持用户自行配置 AI 供应商、流式答案、简短解析及深度思考开关。

## 下载与安装

前往 [最新版本](https://github.com/bcmMC/datitong-releases/releases/latest)，下载 `datitong-版本号.apk` 并覆盖安装。首次安装或更新时，按 Android 提示允许安装此来源的应用。

从旧版升级到 1.3.0 时，请先手动覆盖安装一次；1.3.0 起可在 App 的「设置 → 应用更新」检查、下载并安装后续版本。覆盖安装保留 AI 配置，不需要卸载旧版。

## 发布附件

- `datitong-版本号.apk`：安装包。
- `update.json`：供 App 检查新版本、校验大小和 SHA-256 的版本清单。
- `SHA256SUMS`：文件校验值。

App 下载后还会核对包名、版本和签名；安装由 Android 系统确认，不进行静默安装。

## 仓库范围

此仓库仅发布安装包、更新说明及版本清单，不公开应用源码，不存放签名私钥、API Key 或用户截图。AI 凭证由用户在 App 内自行填写。
